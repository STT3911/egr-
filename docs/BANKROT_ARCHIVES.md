# Компактное файловое хранение Bankrot

Содержимое бизнес-таблиц `bankrot_cases`, `bankrot_case_datasets` и истории
не меняется. Миграция не нужна. Оптимизируются только дополнительные выгрузки.

- В новых строках JSONL общие разделы `manager_*` вынесены в каталог
  `bankrot_cases_<run>_<date>_<time>.managers`. Блок имеет SHA256-имя и сжат gzip;
  одинаковое содержимое записывается один раз на снимок.
- Строка дела содержит `archive_version=2` и `manager_data_ref`. Данные дела,
  решений и прочих разделов остаются в строке. Импорт в БД использует исходные
  данные, до преобразования архивной строки.
- `iter_bankrot_archive(path)` восстанавливает исходный JSON целиком; поддержаны
  прежний JSONL, новые `.jsonl.gz` и смешанная продолжаемая `.jsonl.tmp`.
- Текущая `.tmp` не переписывается и не сжимается. Новый формат дописывается
  после старых строк. При подтверждении страницы архив сбрасывается на диск.
- После успешного импорта файл сжимается. Оригинал удаляется только после
  проверки gzip/CRC, совпадения SHA256 распакованного содержимого и сохранения
  нового пути в `bankrot_sync_runs.output_file`. Если сохранение не удалось,
  оригинал остаётся; следующая попытка безопасна.
- Конкурентные операции сжатия исключены отдельной advisory-lock PostgreSQL.
- `BANKROT_ARCHIVE_KEEP_COMPLETED=0`: **сохранить все снимки**, по выбору пользователя.
  Положительное число включает лимит по времени успешного завершения, не по
  старой дате в имени файла. Незавершённые и содержащие ошибки запуски не удаляются.

Показать план (без изменений):

```sh
docker compose exec -T egr-api python /app/scripts/maintain_bankrot_archives.py
```

Сжать все завершённые выгрузки, ничего из снимков не удаляя:

```sh
docker compose exec -T egr-api python -u /app/scripts/maintain_bankrot_archives.py --apply --keep 0
```

Сначала можно проверить один запуск: добавить `--only-run 36`.
Для ограничения архивов CLI требует отдельно `--keep N --allow-prune`.
Это не команда очистки Docker volumes или БД.

Проверки: `tests/test_bankrot_archive.py`, `tests/test_bankrot_resume.py`.
