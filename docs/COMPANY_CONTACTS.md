# Контакты компании и их источники

Блок карточки использует существующий `contacts_aggregated` из API: ЕГР, МАРТ,
ГИАС, ПВТ и ручные контакты. Новых сетевых загрузчиков и изменений БД нет.
`contacts` сохраняет обратную совместимость и актуальные записи ЕГР, даже если
ночная пересборка агрегата ещё не прошла.

- Контакты сгруппированы по типу: телефон, факс, email, сайт, прочее.
- Совпадающие значения объединяются, все источники сохраняются рядом со значением.
  Регистр email и форматирование телефонов не создают дубликаты. Разные адреса
  электронной почты остаются разными: `.ru` не исправляется на `.com` автоматически.
- Устаревший контакт только из ЕГР не возвращается из запаздывающего агрегата,
  если его уже нет среди текущих `contacts`. Наблюдение того же значения другим
  источником остаётся, но без неподтверждённой отметки ЕГР.
- Подписи источников не означают проверенную доставляемость почты или актуальность
  телефона. Ручные записи не изменяются.
- Сайты открываются только по HTTP/HTTPS; небезопасные схемы и неизвестные типы
  отображаются обычным текстом. Ссылки на почту не принимают дополнительные параметры.

Выгрузка сертификатов БелТПП в текущем загрузчике не содержит контактных полей
и в этот список не включается. Контакты из не подключённых источников не выдумываются.

## Проверка

`frontend/src/lib/companyContacts.test.ts` проверяет слияние, источники,
совместимость с прежним API, просроченные записи и безопасность ссылок.
`frontend/src/components/CompanyContacts.test.tsx` проверяет отображение подписей.
Перед выкладкой выполнить TypeScript, Vitest, production build и ESLint для
изменённых файлов; затем проверить карточку УНП `300293950` в dev и prod.

Выкладка затрагивает только frontend. API, парсеры, БД, сертификаты HTTPS и
сохранённый прогресс судов/Bankrot не требуют перезапуска. Для отката сохранить
предыдущий ID образа frontend перед его пересозданием.
