# Telegram bot

Бот использует те же endpoints, что и веб-сервис:

- `GET /api/v1/companies/lookup` для поиска по УНП или названию;
- `GET /api/v1/companies/{unp}` для карточки компании;
- `GET /api/v1/grp/{unp}` и endpoints `bankruptcy`, `tax-debt`, `risk`, `related` для подробного отчёта.

Поисковая логика не дублируется в боте: Elasticsearch/SQL fallback и нормализация остаются в API.

Этот пользовательский бот не связан со служебным ботом парсеров:

- `TELEGRAM_BOT_TOKEN` — поиск компаний, подписки и персональные алерты пользователям;
- `ALERT_TELEGRAM_BOT_TOKEN` + `ALERT_TELEGRAM_CHAT_ID` — состояние сервиса и ошибки парсеров в служебный чат.

## Переменные окружения

```env
TELEGRAM_BOT_TOKEN=123456:telegram-token
TELEGRAM_BOT_USERNAME=tendex_bot
TELEGRAM_API_BASE_URL=http://egr-api:8000
TELEGRAM_API_KEY=
TELEGRAM_LOOKUP_LIMIT=5
APP_URL=https://test.tendex.by
```

- `TELEGRAM_BOT_TOKEN` обязателен.
- `TELEGRAM_BOT_USERNAME` нужен для одноразовой ссылки привязки из веб-интерфейса, указывается без `@`.
- `TELEGRAM_API_BASE_URL` по умолчанию указывает на API внутри Docker Compose.
- `TELEGRAM_API_KEY` опционален; если задан, бот отправляет его в заголовке `X-API-Key`.
- `TELEGRAM_LOOKUP_LIMIT` задает максимальное число кнопок в выдаче.
- `APP_URL` используется в кнопке перехода из Telegram-алерта в карточку компании.

## Запуск

```bash
docker compose --profile telegram up -d telegram-bot
```

После запуска напишите боту УНП или часть названия компании. 9-значный УНП сразу открывает карточку, а поиск по названию возвращает список вариантов с кнопками.

## Привязка к веб-аккаунту

В центре событий нажмите «Подключить Telegram», затем откройте одноразовую ссылку и запустите бота. Ссылка действует 15 минут и используется один раз.

Если пользователь раньше оформлял подписки командами бота, бот-аккаунт автоматически объединяется с веб-аккаунтом. Совпадающие подписки не дублируются, события и остальные подписки переносятся.

События доставляются задачей `deliver_telegram_events` через основной Celery worker раз в минуту. Изменения по подписанным компаниям перепроверяются не реже одного раза в час.

## Подробный отчёт

```text
/more 193712492
```

Команду `/more` также можно отправить ответом на сообщение, содержащее УНП. Бот проверит ЕГР, ГРП, МНС, банкротство, риск, связи, лицензии, МАРТ, ГИАС, ПВТ, ЕАЭС, планы проверок и БелТПП. Ошибка одного источника не прерывает остальные части отчёта.

Telegram-уведомление содержит тип изменения, название, УНП, значения «было/стало» и ссылку на карточку. Полное досье отправляется только по явной команде `/more`.
